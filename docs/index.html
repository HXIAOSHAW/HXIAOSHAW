LondonZero feasibility agent

Problem
Turn scattered open data about a dangerous London junction into a redesign brief a visual agent can use, without the LLM inventing safety claims.
What I built
Six open datasets (TfL collisions, DfT traffic, OSM, cycling, PTAL, policy notes) filtered by radius, rule-based feasibility scoring, local RAG, guardrail agent, Streamlit UI. A live Nemotron 120B call adds a planning note but cannot overwrite the scored result.
Status
Prototype. Live model call verified; no accuracy benchmark.

MessagePilot AI

Problem
A small shop wants an agent that answers WhatsApp customers and actually acts: orders, payment, refunds. The risk is an agent that refunds or admits fault on its own.
What I built
Intent router, order and complaint agents, PayPal checkout. The LLM judges a complaint; the backend enforces policy: auto-refund only for low-severity cases up to £30 on a real order, everything else becomes an owner task. Deterministic fallback when the model fails.
Status
Prototype on sandbox payments.

PLD Datahub Explorer

Problem
Can London's public planning data tell an infrastructure team where data centres and energy projects are being proposed?
What I built
Config-driven client and pipeline over the Planning London Datahub API. Probed 7 indices (6 reachable), found 147 relevant planning records, 50 directly about data centres, and ranked boroughs by signal.
Status
Exploratory. Heuristic scoring, not a validated model.
